## 1. Authoritative B.2.2 Child Safety API Contract Catalog (`/api/children`)

All endpoints require `Authorization: Bearer <token>` (`authenticateToken`) and verified society membership (`resolveChildSafetyActor`). All responses omit `tokenHash` and `idDocumentHash`. All DB connectivity failures return `503 { error, code: "DATABASE_UNAVAILABLE" }` (or `VERIFICATION_UNAVAILABLE` on gate verify).
